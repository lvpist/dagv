# DAGV

Custom Frappe app for the **Diretório Acadêmico Getúlio Vargas** (FGV): member
registration, the 15 areas, ranks, and automatic provisioning into ERPNext roles
and Raven workspaces.

Built to be **moldable & no-code** for non-technical successors — see the living
spec (`DAGV_NEXO_ERP_spec.md`). Everything subjective is a configurable knob.

## Status
Phase 0 — signup → manual approval → member + Geral workspace.
